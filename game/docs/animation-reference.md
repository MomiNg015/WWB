# 原版动画对照（2026-09-19）

来源：原站 https://godfield.net/ 的公开 `main.dart.js`，工作区 `research/animation-source.txt`（A.fl）、`research/event-source.txt`（A.kq），以及实战视频 https://www.youtube.com/watch?v=OvqoFfxXUMg 。视频中的攻击区、手牌遮片、结算小提示用于外观核对；精确时长以客户端实现为准。没有执行下载的客户端代码。

本轮替换了此前自创的大遮罩、碰撞、飞入和翻牌效果。舞台以攻击方在左、防守方在右开始，反射后交换两列。

| 效果 | 原版参数 | 当前实现 |
| --- | --- | --- |
| 安全 | 280×150，右侧 x370、y130；绿色边框5px；从下方50px上移250ms，停留750ms | 已实现 |
| 反射/乱弹 | 相同尺寸，粉/黄背景；提示1000ms后攻击牌横移340px，750ms | 已实现 |
| 伤害 | 灰底数字，红字白描边；裁切区域内下落150px，150ms+850ms停留 | 已实现 |
| 暗伤害 | 紫底，500ms+1250ms | 已实现，事件增加暗属性标记 |
| 抽牌 | 80×80卡面，上下40px绿色遮片在250ms打开 | 已实现逐张揭示；对手手牌内容不传输 |
| 恢复HP | 绿色HP数字块，上移50px，1000ms | 已实现 |
| 未命中 | 280×100浅黄色块，250ms运动+500ms停留 | 已实现 |
| 升天 | 红底块从y100移至-200，2500ms+500ms | 已实现 |

浏览器实测：铁盾抵挡攻10，伤害块显示6时HP仍50，提示后HP44；神之盾显示安全；超级镜显示反射，随后另一方进入防守阶段。当前63项规则/服务端测试、类型检查和生产构建通过。

## 后续补全

操作提示依据公开客户端 A.jQ / A.jR 与 texts.alerts：确认时检查MP、持有武器时祈祷、空舍弃，使用650×50红色提示条（x15、y180、圆角10、字号30），显示1500ms并播放alert音效。提示不会提交命令或推进回合，重复点击会重新计时。主动选牌与资源提交校验分开，防守禁用仍保留。

| 效果 | 已接入表现与时长 |
| --- | --- |
| 开局 | 640×200提示1500ms，随后每张250ms遮片抽牌 |
| MP/CP | MP数值上移1000ms；CP金币块1000ms |
| 守护神 | 召唤2000+1000ms；出击横移500ms；离开1000+500ms |
| 灾祸 | 独立配色，施加750+1000ms；解除1500+500ms |
| 病症恶化 | 旧病症下移，新病症下落；天国病上下遮片750ms展开 |
| 丢弃/买卖 | 卡片下移或牺牲上移；商品与金币相向移动750+1000ms |
| 购买决定 | 原版粉色300×90控件，“买”y55、“不买”y255 |
| 兑换 | 原客户端箭头SVG；原数值、箭头、新数值分时显示，共2500ms |
| 复活 | 500ms后展示触发神器，再接HP恢复事件，避免直接跳数值 |
| 超常现象/恶魔 | 独立卡面和按能力时长；对应原版音效 |

资源位于 public/assets，播放逻辑为 src/battlePlayback.tsx，时长集中在 shared/presentation.ts。未加入原版没有的碰撞、翻牌或全屏结算遮罩。

仍未穷尽逐帧验证：多人极端连锁、连续清除多种灾祸的并行错峰、梦境揭示中间帧、结束/排行的全部原站状态。当前不能宣称全游戏动画100%还原。
