# 实施顺序与扩展约定

按用户要求：规则逻辑 → 交互动画 → 界面完善。

## 规则

shared/engine.ts 为纯状态转换；actions.ts 和 defense.ts 提供共享合法性。服务器处理身份、权限、随机种子、命令校验和公开视图。客户端不计算权威胜负。

本轮已补齐交易确认、危险道具、死亡连锁、梦境、混乱、守护神特殊能力与多目标队列。63项测试通过，具体证据与未核实规则见 rule-audit.md。

## 动画

服务器输出 BattleCue，客户端按事件队列逐个播放；动画完成前禁用操作，数值跟随对应效果更新。动画不能反过来修改规则结果。时长与形态出处见 animation-reference.md。

## 界面

已接入共享防守禁用规则、购买确认、实际目标状态、资源兑换校验和雾遮蔽。页面保留原版固定画布与素材。结束页、排行等状态仍缺完整原站逐状态对照；不能据测试通过宣称全界面完全一致。

## 新玩法

数值差异通过 Rules；能力通过效果处理器；新增命令同时修改协议、服务器校验和纯引擎。新增规则需验证非法命令原子性、多人目标顺序、资源边界、死亡与重连投影。视觉效果只消费新事件。
