# God Field 复刻工程

React + TypeScript + Vite 前端，Node.js + Express + Socket.IO 权威服务器，独立的确定性规则引擎。

## 运行

需要 Node.js 22 或更新版本。在本目录执行：

```sh
npm ci
npm start
```

浏览器访问 http://127.0.0.1:5173 。前端 5173，服务端 3311。可在两个独立浏览器会话中输入相同房间口令测试多人游戏；普通同源标签共享账号，测试两名玩家请用隐身窗口。默认仅监听本机，不是公网部署。

```sh
npm run typecheck
npm test
npm run build
```

构建后 `npm run server` 可直接从 http://127.0.0.1:3311 提供静态页面及实时接口。`GAME_PORT` 可改端口，`GAME_DATA_DIR` 可改账号数据目录。

## 当前交付范围

- 姓名入口、模式菜单、修行配置、私密房间、个人/组队准备、聊天、末日设置、匹配、排行、战斗、图鉴、语言与音量设置。
- 296 条原站公开道具数据和对应本地图片；十类教典，按原站布局提取的分类位置。
- 服务器校验回合、卡牌归属、资源与房间权限；对手手牌及随机种子不下发；断线身份恢复、机器人、胜负与本地积分。
- 攻击/防御、顺序组合、属性、反射/乱弹、奇迹、兑换、买卖确认、灾祸、梦境、混乱、危险道具、复活/临终攻击、守护神与超常现象。

**这是可运行的独立重建，不能宣称所有隐藏规则和界面状态 100% 一致。** 浏览器无法取得原站私有服务端源码。63项测试、类型检查与生产构建通过；概率分布和极端组合仍需更多原站证据，本地 Elo 也不是原站已公开公式。详见 [规则核对](docs/rule-audit.md)、[研究与差异](docs/research.md) 和 [视觉验收](design-qa.md)。

| 目录 | 职责 |
| --- | --- |
| `src/App.tsx` | 屏幕路由、通用控件、图鉴、战斗组件 |
| `src/game.css` | 原站固定 1080×720 画布样式 |

## 加玩法

1. 数值变体：向 `createGame(players, overrides, seed)` 传入 `Partial<Rules>`，例如 `{initialHP:100, initialMP:20, handSize:12, maxStat:120, maxHandSize:24}`。不要改前端来决定服务端结果。
2. 新道具效果：在数据中添加 `ability`，在 `effects` 注册处理器；有防御窗口的效果通过行动队列结算。攻击/死亡触发类效果需在对应阶段增加处理，并写组合与回滚测试。
3. 新命令：同时扩展 `Command`、服务器 Zod 校验和 `reduceGame`。客户端只提交意图，广播使用 `projectGame` 防止隐藏信息泄漏。
4. 新模式：在服务器增加模式配置入口，将规则参数写入每局 `Game.rules`，前端添加相应配置。模式差异不要散落在 CSS 或 UI 回调里。
5. 可复现调试：保存初始 seed、玩家配置、规则和命令序列，用 `reduceGame` 重放；当前未实现持久化回放界面。

会话/积分保存在 `data/sessions.json`；房间和进行中的对局仍驻留内存，服务器重启不会恢复对局。上线前还需要数据库、持久化对局、连接限流、监控与部署配置。原站素材及名称的权利归原作者；本工程未获得素材再发布许可，不应把可下载视为可商业再发布。
